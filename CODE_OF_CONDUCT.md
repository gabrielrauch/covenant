# Code of Conduct

## Focus

This project is focused exclusively on software development. Discussions should remain technical and related to the project's goals.

## Guidelines

- Keep discussions technical and on-topic
- Provide constructive feedback on code and design decisions
- Document your contributions clearly
- Follow the existing code style and conventions
- Test your changes before submitting

## Pull Requests

- Describe what your PR does and why
- Reference related issues when applicable
- Keep PRs focused and reasonably sized
- Respond to review feedback promptly

## Issues

- Search existing issues before creating new ones
- Provide enough context to reproduce bugs
- Be specific about feature requests

## Enforcement

Maintainers reserve the right to close issues, reject PRs, or remove comments that are off-topic, spam, or not constructive to the project's development.
